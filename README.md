# Abhinav MV — Portfolio

Personal site built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Motion and next-themes.

```bash
npm install
npm run dev
```

All content lives in `src/content/profile.ts`. Replace `public/Abhinav_MV_Resume.pdf` to update the downloadable resume, and set `siteUrl` once the site has its final domain.

Deploy by importing the repo into Vercel; no extra configuration is needed.

Design research notes: `docs/research/modern-portfolio-design.md`.
